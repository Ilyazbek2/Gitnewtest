# Python Problems

Пять небольших задач по Python: условия, решения и примеры вызова находятся в отдельных файлах.

## Задачи

1. [Два числа](problems/01_two_sum.py) - найти индексы двух чисел с заданной суммой.
2. [Проверка скобок](problems/02_valid_parentheses.py) - определить, правильно ли расставлены скобки.
3. [Сжатие строки](problems/03_compress_string.py) - заменить группы одинаковых символов их количеством.
4. [Самый длинный отрезок](problems/04_longest_unique_substring.py) - найти длину подстроки без повторяющихся символов.
5. [Слияние интервалов](problems/05_merge_intervals.py) - объединить пересекающиеся интервалы.

Все решения используют только стандартную библиотеку Python.
